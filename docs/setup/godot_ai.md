# Godot AI 与 Trae 配置

项目已启用 Godot AI 4.2.3、GdUnit4 6.2.1 和调试用 `_mcp_game_helper`。

1. 使用 Godot 4.7.2 打开本项目。
2. 在项目设置 → 插件确认 Godot AI 与 GdUnit4 已启用。
3. 打开 Godot AI 面板，在客户端列表选择 Trae，点击 Configure。
4. 若客户端提示重新加载，重新加载 Trae；保持编辑器打开。
5. 调用编辑器状态工具，确认返回的项目为 **ProjectFactory**。
6. 场景修改保存后运行项目；检查日志并获取截图，验证结束停止游戏。

客户端路径、端口、MCP 配置都属于机器设置，不写入仓库。不要复制其他项目的固定端口。
如果没有连接，先检查当前项目插件是否启用、编辑器与 MCP 服务是否在同一机器/网络环境。

AI 工具不可用时仍可直接改源码并运行无头检查；交付记录需说明未完成的实时验证环节。
项目级 Skills 位于 `.trae/skills/`；日常工作以 AGENTS 中的明确授权和强制 TDD/独立审查流程为准。
