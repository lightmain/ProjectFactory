定向核对现有源码、规格与 RustConveyor API。初审未报告 Critical，

| 发现 | 文档处理 |
| --- | --- |
| 同步实例不能直接搬到后台线程 | 停止同步测试会话，工作线程按同夹具重新创建；运行现场恢复等待已验证检查点 |
| UI／重生验收缺少碰撞依赖 | M12 完整验收加入 M07，输入适配仍可提前开发 |

| 取消窗口晚于可见索引切换 | Committing 前关闭取消；同步失败 CommitUncertain 保留新旧文件并恢复确认 |
| 加载缺少双方共享提交决定 | 世界线程唯一排序，可靠幂等决定，宿主切换确认后才激活并释放旧世界 |

| 时间合并丢编辑时刻 | 保留事件位置、余量、补偿与 flushed；禁止跨事件合并并要求等价重放 |
| latest-only 分页可能永远不完整 | 在途固定快照、完整页清单、跨批协调安装、有界待领轮次与显式超时中止 |
| 自由镜头与编辑修订缺少碰撞保护 | 两种运动扫掠范围／修订覆盖；缺失时限制或使用 Rust 权威数据扫掠 |
| 已接受操作无可靠终态空间 | 接受前预留输出额度，独立控制额度，result_seq 与命令退休水位分离 |
