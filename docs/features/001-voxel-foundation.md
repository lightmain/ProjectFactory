# 001：体素工厂基础框架

维护类型：当前世界规则与验收。开发约束见 [AGENTS](../../AGENTS.md)；
玩家运动与物品栏契约见 [对应规格](002-player-and-inventory.md)。

## 目标与验收

提供可直接运行的第一人称体素沙盒，为后续工厂系统提供世界规则层。

- 每格边长固定为 0.5 米，世界坐标采用格子最小角，负坐标向下取整。
- 世界默认 32×32 格（16×16 米），地表 y=0，地下四层；可建造高度 8 米。
- 水平格子范围 `[-16, 16)`；垂直范围 `[-4, 16)`。最底层基岩不可破坏。
- 左键破坏、右键沿命中面的法线放置。
- 交互距离 5 米。禁止覆盖已有方块、越界放置、放进玩家身体、放置非法类型。
- 初始世界平坦，草地、泥土、石头、基岩分层；1/2/3 选择草地/泥土/石头，无限库存。
- Esc 释放或捕获鼠标；鼠标释放时移动与编辑停止；重新点击只捕获鼠标。
- 走出世界后坠落自动重生，在原出生位置水平范围内当前最高方块上方重生，
  检查完整玩家身体占用范围并清零速度。当前不提供保存、无限地图或多人联机；
  设施类型与建造操作见 [基础物流规格](003-basic-logistics.md)。

## 结构与决策

- `scripts/core/`：纯数据 `VoxelWorldData`、格子射线 `VoxelRaycast`、命中结果 `VoxelHit`。
- `scripts/world/`：按 8×8×8 格构建可见面网格和碰撞；修改仅重建相关区块。
- `scripts/player/`：第一人称运动、输入信号；通过参数向规则层提供玩家占用范围。
- `scripts/ui/factory_hud.gd`：世界 HUD，展示控制提示、选中类型与目标。
- `scenes/main.tscn` 负责装配，`scenes/player.tscn` 封装玩家。
- 世界数据是唯一真实状态；射线使用数据而非刚重建的物理网格，避免交互滞后一帧。
- 表现通过信号接收实际修改，通用层次约束见 AGENTS。
- 小型有限世界采用字典与区块可见面网格，不为每个方块创建节点。
- 区块碰撞重建在 `_physics_process` 进行，优先级 -100，先于默认优先级玩家运动。
- 射线同时跨越多轴时逐轴处理，固定 X/Y/Z 优先级，棱角擦过视为命中；
  初版保留该确定性策略，后续可按玩法需求调整。
