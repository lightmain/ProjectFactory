# 007：多存档与简洁菜单

所属版本：prealpha-1。状态：当前规则。
继承 [006](006-session-and-save.md) 的区块快照、暂停和失败保护；
替代其中单槽及菜单规则。此前 HTML 草案不再作为实施依据。

## 规则

- 世界是一局新游戏，开局输入名称，当前不支持世界改名；唯一 ID 不可改。
  存档是该世界某时刻的完整快照，每份记录世界名称与 ID。
- 主界面：新游戏、继续、载入游戏；继续读取全局最新成功存档。
  Esc：继续、载入游戏、保存游戏、保存并退出。
  载入成功丢弃当前未保存进度，不另弹保存询问；失败保留原暂停现场。
  保存并退出写固定名称“退出存档”，成功后返回主界面。
  同名退出档自动覆盖；若与手动档同名，先确认覆盖。
- 载入列表按保存时间倒序；单击选择后确认或双击载入。
  每行右侧删除按钮，删除必须二次确认。
  Esc 先关闭确认框或子菜单，再恢复游戏。
- 保存界面复用列表，顶部名称默认“世界名称_年月日时分秒”；
  可编辑，点击行采用该行名称，确认保存；同名二次确认覆盖。
- 自动保存每 x 分钟一次，每世界 ID 最多保留 y 个自动档，超限删最老自动档；
  x、y 可配置，默认 5 分钟、3 份，暂停不计时。索引维护各世界自动档列表，
  不为统计数量逐份读取快照；不淘汰手动档，失败不删旧档。
- UI 黑白灰工业风，清晰字体层级、等距排版，去掉橙色按钮与彩色装饰。

## 存储与验收

自动保存配置在 `config/game_config.tres` 的 `autosave_interval_minutes` 与
`autosave_retention`。索引为 `user://saves/world/index.bin`，快照放在其
`snapshots/` 下；新快照验证并提交索引后才清理旧档。旧单槽仍可从列表读取。
验收入口为 `tests/integration/test_multiple_saves.gd`、
`test_factory_session.gd`、`test_session_menu.gd` 和真实启动探针；
当次证据见 [审查记录](../../reviews/007-multiple-saves.md)。

2. 会话与自动保存：接入世界身份、最新档继续、自动计时与每世界轮换；测试暂停、跨世界和失败不丢现场。依赖 1。
