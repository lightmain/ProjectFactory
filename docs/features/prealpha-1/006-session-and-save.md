## 行为与验收

- 默认世界为 64×64×64 格，每格仍为 0.5 米；水平 `[-32,32)`，
  垂直 `[-4,60)`，地表 y=0，地下草地、泥土、石头、基岩各一层。
  数据区块为 32³，以世界最小格为索引原点，恰好 2×2×2 个区块。
  渲染区块继续使用 8³，数据区块不直接决定碰撞网格大小。
- 启动进入主菜单，提供新世界、读取存档、退出；没有活动世界时不运行物流。
  新世界不立刻覆盖旧存档；已有存档时提示下次保存会覆盖。
  **菜单与覆盖提示已被 [007](007-multiple-saves.md#规则) 替代。**
- 游戏 Esc 打开暂停菜单；库存打开时第一次 Esc 仅关闭库存。
  暂停时玩家、自由镜头、物流和游戏时间全部停止，鼠标可操作菜单。
  Esc 或继续关闭暂停菜单；恢复原视角、捕获状态，并屏蔽残留跳跃。
  暂停菜单提供保存、读取、保存并返回主菜单。保存失败时保持暂停并显示错误。
  **菜单操作由 [007](007-multiple-saves.md#规则) 扩展；暂停及失败保护继续有效。**
- 本轮一个本地存档槽，位于 `user://saves/world/`。存档记录世界生成器版本、
  初始地形模式、区块改动、玩家位置/速度/出生点/视角、工具与朝向、库存，
  物流时钟、机器方向、生产相位、库存、输入轮询、矿石身份/入向/进度。
  同时保留尚未结算的连接与转向、已有矿机及后续放置的生产参数；
  加载为会话创建独立配置，不修改共享 `.tres`。
  读档恢复后相同 delta 下工厂继续得到相同结果，不补算离线时间。
  未提交的建造线路、库存界面、自由镜头位置不保存；加载进入第一人称。
  **单槽限制已被 [007](007-multiple-saves.md#规则) 的多存档替代；快照范围继续有效。**
- 相对确定性初始地形只存不同格子，包含被挖成空气的格子；
  未修改区块和编辑后完全恢复原状的区块不写入文件。
  初始平地由生成器重建，不以“经过即保存”扩大存档。
- 每个区块采用局部 uint16 索引 + uint8 方块编号的差异记录，DEFLATE 压缩。
  文件有未压缩长度及 SHA-256 校验。基础世界无需逐格写盘。
- 保存采用两个代次目录：先完整写入非活动代次，再以临时文件重命名切换
  活动指针；写入失败保留当前存档。读档先完整验证并重建独立数据，再替换活动世界。
  缺文件、损坏、未知版本、非法边界/类型/机器或库存状态给出错误，不修改活动游戏。
  文件限制和已知字段校验避免异常存档扩散到游戏规则。

## 会话与数据边界

`scenes/session.tscn` 为启动入口，`FactorySession` 管理世界生命周期，
并装配持续接收菜单输入的 `SessionMenu` 和可暂停的 `FactoryGame`。
`scenes/main.tscn` 保留为可独立实例化的游戏场景。
玩家发出暂停请求，库存优先关闭；会话停止整棵游戏子树及物理世界，
恢复时重新启用原有视角与输入状态。

`VoxelWorldData` 根据生成器查询初始地形，第一次修改某区块时才分配区块数据。
`SessionSnapshot` 在独立数据上校验和恢复，不触碰活动场景；
已结算拓扑必须包含所有合法连接，矿机相位须与结算时刻一致，
矿石队列须满足运行求解器的间距约束，并在整张已结算图上验证零时间位置可行性，
避免闭环误差累积。快照不序列化节点或 Resource 对象。

`SaveGameStore` 负责文件 I/O。`current` 仅包含 `a` 或 `b`；
各代次含 `session.bin` 与实际修改的 `chunk_x_y_z.bin`。
**根目录布局已由 [007](007-multiple-saves.md#存储与验收) 扩展；
以下双代次编码现应用于每份独立快照。**
每个二进制文件头为格式标识、未压缩长度和 SHA-256，后跟 DEFLATE 数据。
会话文件仅使用不允许对象解码的 Godot Variant 二进制格式；
区块文件使用上述差异记录。会话未压缩长度上限 16 MiB，
每区块上限为 32³ 条记录；最多 8 个区块。
本轮允许保存的有限物流时钟上限为 10⁸ 秒。

Godot 4.7.2 / typed GDScript / GdUnit4，复用内置 FileAccess、DirAccess、
PackedByteArray 压缩；不引入数据库、第三方存档插件或游戏 Autoload。
`scripts/core/` 保存纯数据与快照，`scripts/` 会话入口装配，
`scripts/ui/` 发出操作请求。风格与安全边界遵循 [AGENTS](../../../AGENTS.md)。

本轮同步保存适用于 8 个测试区块；无限世界、后台流式加载、异步保存、
区块调色板/位打包、多槽 UI 和旧存档迁移未纳入范围。
**多槽 UI 已由 [007](007-multiple-saves.md) 实现；其余范围不变。**
扩大世界前仍需改造全世界枚举、渲染加载与后台模拟范围。
