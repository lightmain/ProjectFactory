# 009：45° 斜坡传送带

所属版本：prealpha-1。状态：当前规则。面向开发与验收，继承
[基础物流](003-basic-logistics.md)、[世界建造朝向](004-free-camera.md)和
[区块存档](006-session-and-save.md)。斜坡是独立的单格物流设施，
不使用 [多方块结构](008-multiblock-structures.md) 的实例表或占用索引。
本规格扩展 003 的“仅同高度连接”边界；003 的平带自动寻路仍只铺平带。
**自动线路仅平带的限制已由 [010 的混合直角线路](010-orthogonal-belt-routes.md)
替代；本规格的单格几何、直行端口、运输及 8／9 工具继续有效。**

## 行为与验收

- 数字键 8 选择上坡，9 选择下坡；均为无限建造工具。R 选择世界水平四向，
  切换工具保留朝向。一次右键放置一段，左键拆除一段。
  平传送带自动绕障仍只铺平带，不能把斜坡当作可转弯或可重定向的路径格。
  **本句“自动绕障仍只铺平带”已由 [010](010-orthogonal-belt-routes.md) 替代；
  已有斜坡仍不能作为可重定向端点，线路中间可从其带缘上方跨过。**
- 每段水平前进 0.5 米、升高或降低 0.5 米，带面为 45°。
  上坡低端进、高端出；下坡高端进、低端出。只有后方入口和前方出口，
  不接受侧面输入、不在带内左右转弯、不分流。R 仅旋转待放置段，
  不改变已放置且载矿的斜坡。
- 一个最低格坐标保存一台设施，独占该格；高低端不分配额外方块或结构 ID。
  带面继承平带的竖直厚度，低端顶面在基准格底部上方 0.08 米，
  高端顶面比低端高一格。因此高端带缘少量越过上方格界，
  必须检查实际实体与上方设施、世界顶界、玩家和自由镜头的相交；
  上方格仍为空，不成为斜坡的占用格。预览与提交共享限制。
- 同方向斜坡可连续连接，平带可接低端或高端；矿机与箱子沿用既有端口，
  连接要求水平相邻、出口方向匹配且端口高度相同。
  上坡后继基准格高一格，下坡后继斜坡基准格低一格；
  高度或入口方向不匹配时保持堵塞，不能隔格或凭空升降运输。
- 容量、单段运输时间、交接时钟、队列顺序和堵塞传播继承平带；
  矿石沿斜坡中心线连续升降，跨连接保持身份与数量，不倒退。
  同样的单段运输时间意味着斜坡的实际路程较长；暂不新增速度配置。
- 虚影、箭头、端口、实体网格、三角碰撞与格子射线都采用斜面，
  射线能穿过带下空隙并命中倾斜带面与越过格界的带缘。
  选中框覆盖整段实体范围；暂停、库存及失焦沿用现有预览规则。
- 保存并恢复上下坡、水平朝向、矿石身份与进度、端口连接及所选工具；
  新会话格式读取旧格式 1／2。拒绝旧格式夹带新类型、斜坡方向与类型不符、
  非法侧向矿石、错误高低连接或与世界实体冲突的快照。

## 数据与实现约束

复用字节型区块类型编码，以八种上下坡／水平朝向组合保存单格几何；
物流仍以格坐标索引一份设施状态。朝向与斜面从同一编码读取，
避免世界碰撞和物流方向各自维护后产生差异。不用独立场景节点表达占用，
复用 `SurfaceTool` 区块网格、物流采样和物品渲染池。
几何与端口计算放在核心规则层，不查询节点树或物理世界。
拓扑仅检查固定数量的相邻候选，维持每逻辑批次与采样的最坏线性复杂度。

会话格式为 3，继续读取格式 1／2；不改变区块差量的三字节记录或文件封装。
**格式版本已由 [011](011-pressure-save.md#编码与范围) 替代为格式 4，
继续读取格式 1／2／3；本节的方块类型、斜坡和旧格式类型校验规则继续有效。**
类型 9–12 为上坡、13–16 为下坡，各组顺序为 +Z、−X、−Z、+X。
所选工具仅保存 9／13，另存水平旋转；已放置设施的编码即其固定朝向。
旧格式仍按各自类型范围校验，不能仅修改版本号后夹带新类型。
带面使用竖直剪切的薄长方体，不以实心楔体填满下方空隙；
区块网格及三角碰撞、预览的 `BoxMesh` 变换和核心射线采用同一坡度。
矿石复用原球体和竖直离地偏移，不参与物理碰撞或端口判定。
